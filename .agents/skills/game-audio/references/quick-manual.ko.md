# Game Audio 간단 설명서

`$game-audio 설명서` 요청에는 아래 내용을 짧게 요약한다. 설치·계정 조회나 생성은 실행하지 않는다. 세부 설정을 묻지 않았다면 명령어·JSON 전체를 나열하지 말고 기본값, 옵션 표와 요청 예시 2~3개를 보여준다.

연기가 필요한 **캐릭터·NPC·보스 대사는 Gemini 3.8 Flash TTS + 밀도 강화**가 기본이다. 일반 안내·내레이션은 **Eleven v3**, 효과음·환경음은 **Sound Effects v2**, BGM은 **Music v2.5**를 사용한다. Gemini 키가 없으면 설정을 안내하고 목소리를 임의로 다른 제공자로 바꾸지 않는다. 그 외 자동 선택에서 ElevenLabs 접근 수단이 없으면 이용 가능한 로컬 모델을 사용한다. `로컬만`을 지정하면 원격 API를 사용하지 않는다.

대사는 **이미 채택한 캐릭터의 모델을 우선 유지**한다. **v4는 직접 요청하거나 해당 캐릭터에서 이미 채택한 경우** 사용한다. 현실적인 NPC·내레이션에는 v4 비교를 제안할 수 있지만, 자동으로 바꾸지 않는다. ElevenLabs Voice Design에는 v4 연기·음질 제한도 안내되어 있다. Gemini의 Voice Design과는 별개의 제한이다.

| 정할 수 있는 것 | 말하는 방법 / 선택지 |
| --- | --- |
| 사운드 종류 | 효과음, 군중·바람 같은 환경음, 캐릭터 대사, BGM |
| 제공자·모델 | 연기 대사는 기본 Gemini / 일반 내레이션·효과음·BGM은 ElevenLabs / `로컬로`. ElevenLabs 대사를 선택하면 기본 `v3`, `v4`·`v4 Turbo`를 명시 선택 가능. 로컬 BGM은 ACE-Step 1.5와 Stable Audio 3 중 선택 가능 |
| 캐릭터 목소리 | 기존 캐릭터·voice ID 유지, 또는 Gemini로 새 가상 목소리 설계. 고정 음색과 매 대사의 감정은 따로 지정 |
| 대사와 연기 | 정확히 말할 문장, 언어, 평상시·속삭임·위협·분노·웃음 등 상황. 기본은 자연스러운 대화 속도이며 `조금 빠르게`, `느리고 무겁게`, `한국어/영어 연기 지시 비교`도 가능 |
| 대사 보정 | Gemini 기본 `밀도 강화`, `보정 없이 원본`, 또는 EQ·작은 발음 보강·보스룸 잔향 등 별도 비교 요청. 원본은 항상 보관 |
| 길이·후보·반복 | `3초`, `후보 3개`, `끊김 없는 루프`, 애니메이션의 타격 시점. 대사 길이는 실제 발화에 따라 결정 |
| 출력·확인 | 기본 WAV 48 kHz / PCM24, 필요에 따라 모노·스테레오. 파일만 전달하거나 재생·비교 웹앱 요청 |

예시:

- `$game-audio 수도원 청동종 같은 전설 아이템 획득음, 2초짜리 후보 3개 만들어줘.`
- `$game-audio Gemini로 기존 마법사 목소리를 유지해서 "여기서 물러서라"를 차분함과 분노로 만들어줘.`
- `$game-audio 방금 Gemini 대사를 보정 없이 원본과 밀도 강화로 비교해서 재생하게 해줘.`
- `$game-audio Stable Audio 3로 어둡고 긴장되는 보스 BGM을 30초 루프로 만들어줘.`

밀도 강화는 부드러운 EQ와 압축으로 음량 편차를 다듬는다. 불명확한 발음을 새로 복원하거나 모든 음성에 최선임을 보장하는 기능은 아니다. `작은 발음 보강` 같은 다른 보정은 별도 로컬 편집·비교 요청이며, 현재 런타임의 이름 있는 후처리 프리셋은 `density` 하나다.

설정을 물으면 필요한 부분만 안내한다: 실행 호스트의 런타임 아래 `.secrets/elevenlabs_api_key`, `.secrets/gemini_api_key`에 키만 저장하며 채팅에는 붙여 넣지 않는다. 로컬 모델은 별도 설치가 필요하다. 다른 컴퓨터에서 쓰려면 스킬과 전체 런타임을 함께 설치한다. 자세한 내용은 [실행 위치·설치](execution-setup.ko.md), [캐릭터 음성](character-voices.md), [명령·요청 형식](runtime.md)을 따른다.
